## 💡 주요 기능
1. **📖 기초 개념 7단계 마스터 코스**
   - HBM 3D 적층 원리, 직렬 열 누적 메커니즘, TIM 접촉저항 병목, 1D 모델 수식 분해, 공랭 물리적 한계, 경제성 손익분기점 체화
2. **📊 1차원 열저항 직렬 모델 & 실시간 시뮬레이터**
   - DRAM 적층 수(4Hi~16Hi), 주변온도, TIM 열전도도($k$), 실장 두께(BLT), 접촉 열저항($R''_c$) 슬라이더 조작
   - 실시간 $T_{max}$ 계산, 허용 열저항($R''_{allow}$) 역산 및 공랭 한계 도달 여부 판정
3. **🎯 AI 심사위원 모의 디펜스 (9대 급소 질문)**
   - 1D 모델 가정, 교차검증 오차, 접촉열저항 지배, 공랭 한계의 공학적 의미, 재작업률 비용 분석, 로직 다이 고발열 밀도, 상변화 물질의 잠열 vs 젖음성, 펌프아웃 장기 신뢰성, 데이터센터 공조 연계
   - 타이핑 답변 입력 시 지능형 평가 엔진이 등급(S/A/B/C) + 강점 + 보완점 + 실전 발표장 100점 모범 답변 스크립트 즉시 제공
4. **📝 오답노트 & 히스토리**
